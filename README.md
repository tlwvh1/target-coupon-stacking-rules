## target coupon 到底指哪几种券

先分清对象。搜这个词时你碰到的通常有三样东西，规则各不相同。

**Target 券**：券面印着 "Target Coupon"，Target 自己发放。包括店内纸质券、App 数字券，以及 Target.com 上的促销码——后者是字母数字组合，结账时填进 promo code 输入框。

**制造商券**：印着 "Manufacturer Coupon"，品牌方发放，比如 HUGGIES 湿巾减 $1、Suave 洗发水减 $4 这类。打印出来的互联网制造商券可以用，前提是有可扫描条码；Target Circle 里收录的数字制造商券也能用。

**Target Circle offer**：Circle 是 Target 的免费会员体系，在 App 里把优惠 clip 到账户，结账自动生效，不需要出示任何券。官方帮助文档明确写着 Circle offer 按件计，可以和上面两类券同时叠在同一件商品上。

三样东西对应三个折扣层，这就是 Target 叠券的基本盘。

## 叠加规则：三层怎么叠，哪些细节容易翻车

每件商品可以同时吃三层折扣：1 张制造商券 + 1 张 Target 券 + 1 个 Circle offer。下面这张表把各层的限制归拢在一起：

| 层级 | 类型 | 数量限制 | 备注 |
| --- | --- | --- | --- |
| 第一层 | 制造商券（纸质/数字） | 每件商品 1 张 | 打印版需有可扫条码 |
| 第二层 | Target 券（纸质/数字/促销码） | 每件商品 1 张 | 可与类别券叠加 |
| 第三层 | Target Circle offer | 每件商品 1 个 | App 内 clip 后自动生效 |

规则里有几处容易被忽略的地方，直接决定你最后省多少：

1. **"One coupon per purchase" 是按件算的**。买 5 瓶洗发水，同一张券可以用 5 次；写 "per transaction" 才是每单限一张。
2. **类别券门槛按用券前的原价算**。比如 $5 off $15 的 Personal Care 类别券，看你用券前该类商品是否满 $15。官方自己举的例子就是：$1 off 沐浴露的商品级 Target 券，可以和 $5 off $15 类别券叠加用。
3. **每户每天每种相同券限 4 张**，除非券面另有说明。囤货翻车大多翻在这里。
4. **BOGO 券不能互相叠加**。两张 BOGO 不能让两件都免费；用制造商 BOGO 券时，第一件可以再叠一张 Target 减现券，反过来同理。
5. **销售税按制造商券抵扣前的全价算**。$10 的东西用掉 $2 制造商券，税还是按 $10 计；Target 券则会降低应税金额。买大件时这个差异能感觉到。
6. **退货规则不对称**：制造商券买的东西退货，券值以 Target GiftCard 返还；Target 券的券值退了就没了。

清仓区默认不参与 Circle deals，除非页面另有标注。另外店内 CVS 药房的商品不适用 Target 券和 Circle offer。

顺便说一个冷门项：Target App 里可以给酒类添加数字制造商返利（DMR），结账后一小时内通过 PayPal 收到返现，但只在部分州可用、仅限店内，返现金额也不会显示在 Target 小票上。

## 常见问题

**Target.com 的促销码在哪儿输入？**
结账页的 promo code 输入框。促销码是字母数字组合（TGTXXXXX 这类格式）。过期码、非在售商品的码、无购买条件的免费商品码、仅限门店的券都不接受。

**手机上的制造商券能用吗？**
纸质制造商券不能靠手机截图出示，但 Target Circle 里收录的数字制造商券可以用。想用制造商券，要么打印带条码的版本，要么在 Circle 里领数字版。

**用券会影响 TopCashback 返现吗？**
券本身不影响——返现追踪的是通过链接完成的订单。但 TopCashback 条款里写明，使用其页面上未展示的优惠码可能导致返现被取消，所以促销码尽量从 TopCashback 商家页拿。

**TopCashback 收费吗？**
注册和使用免费，无需信用卡。PayPal、Venmo、银行转账提现无最低金额，部分礼品卡除外。

**返现要等多久才能到手？**
订单一般 7 天内被追踪，Pending 状态要维持到商家退货期结束（数周），变 Payable 后 PayPal/Venmo 约 1–2 个工作日到账。这是一笔慢钱，急用就别指望它。
